# Murugan — Portfolio

An immersive, scroll-driven portfolio site for Lord Murugan.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # static site → ./out
```

- Project brief: `CLAUDE.md` · Technical spec: `BUILD_SPEC.md`
- All copy: `lib/content.ts`
- Raw assets live in `Assets/`; web versions in `public/media/` (rebuild with `npm run media`).
